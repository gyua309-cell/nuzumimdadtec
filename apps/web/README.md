# @idham/web — واجهة إدهام موارد بشرية المحاسبي

React 19 + Vite + TypeScript + TailwindCSS 4، عربي RTL أولًا مع الوضع الليلي.

## التشغيل محليًا

من جذر المشروع:

```bash
npm run db:start      # قاعدة PostgreSQL المحلية (نافذة مستقلة)
npm run db:migrate    # تطبيق ترحيلات قاعدة البيانات
npm run dev:api       # الخادم على http://localhost:3000/api/v1
npm run dev:web       # الواجهة على http://localhost:5173
```

عند أول فتح يظهر **معالج الإعداد الأولي** (الشركة، العملة الأساسية، السنة المالية الأولى، حساب مدير النظام).

## مبادئ

- الواجهة تتصل بالـ API فقط (`/api` عبر Vite proxy)، ولا تتصل بقاعدة البيانات أبدًا.
- رمز الدخول في الذاكرة فقط؛ رمز التحديث كوكي `httpOnly` من الخادم.
- لا بيانات تجريبية؛ كل رقم معروض قادم من الـ API.
- المبالغ نصوص عشرية وتُجمع بـ `decimal.js` (لا أرقام عائمة).
- `localStorage` يحفظ تفضيلات الواجهة فقط (الثيم، الشركة المختارة).
